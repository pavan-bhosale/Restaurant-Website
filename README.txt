El Ñaño Miami: one-page site
Open index.html (double-click). No build step, no internet needed.

Brand font: drop HolidayFree.woff2 (or .otf) into assets/fonts/. Until then headings use Archivo.
Photos: assets/img/. Replace any file with a higher-resolution version using the same filename.
Logo: assets/logo/ (SVG + transparent PNG, yellow and green).
